# Star Defender — Windows releases

Репозиторий готовых сборок и обновлений Star Defender. Исходный код игры здесь
не публикуется. Новые версии будут доступны в разделе **Releases**.

Первый релиз со встроенным обновлятором:
[2026.10.1.1](https://github.com/playernikita/star-defender-releases/releases/tag/v2026.10.1.1).

## Установка

Сохраните всю папку игры: `Star Defender.exe`, `_internal`,
`Star Defender Updater.exe` и `build-info.json` должны оставаться вместе.
Не переносите один EXE отдельно от остальных файлов.

## Обновления из игры

Начиная с версии **2026.10.1.1**: Настройки → Обновления → Проверить наличие
обновлений. Ознакомьтесь с изменениями, скачайте новую версию и подтвердите
установку. Перед установкой вернитесь в главное меню и выйдите из сетевой комнаты.
Игра закроется, обновится и запустится снова.

Файлы обновлений проверяются по цифровой подписи и SHA-256. Сохранения и настройки
не заменяются. Предыдущая полная версия остаётся рядом в папке `.previous-...`.
При недоступности сервиса можно продолжить играть и установить сборку вручную.

Старые версии без вкладки «Обновления» сначала нужно обновить вручную.

---

This repository hosts Windows builds and update packages, not game source code.
Keep the EXE, `_internal`, updater and build marker together. From version
2026.10.1.1, use Settings → Updates to check, read release notes, download and
confirm installation. Saves and preferences are preserved, and the previous
version is retained beside the installation for rollback.
